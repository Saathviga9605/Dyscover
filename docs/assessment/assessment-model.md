# Assessment model

Assessment domains are defined in `backend/app/assessment.py` and mirrored in the frontend type layer. A game definition describes an activity; a game session is one run; a trial is one stimulus-response unit; interaction events preserve the event stream.

Initial domains are visual-symbol discrimination, orthographic recognition, phonological awareness, working memory, sequencing, attention/visual search, reading fluency, and interaction behavior. They are dimensions for structured observation, not individual diagnoses.
