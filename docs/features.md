# Feature definitions

The initial behavioral extractor computes overall and per-domain accuracy, incorrect response rate, mean/median/variance of reaction time, hesitation, error count, completion rate, pause count, hint count, and per-game accuracy/timing. Each feature has explicit metadata and availability.

Gaze, speech, and NLP are separate future providers. A missing modality is represented as unavailable. These features describe observed activity behavior and are not individually diagnostic.
